# Utførelsesoppdrag

Denne mappen er valgfri. Den brukes når en agent trenger et presist oppdrag som kan overtas mellom økter. Den er ikke en parallell personlig oppgaveliste.

Bruk [oppdragsmalen](../maler/oppdrag.md). Utkast blir klar først når mål, kilder, målflate, fullmakt og ferdigkriterium er avklart. Utføreren setter pågår og fører fremdrift i samme fil. Blokkert angir konkret hindring og gjenopptak. Fullført krever verifisert resultat, oppdatert eieroppgave og flytting til arkiv.

Ingen fil her starter en agent av seg selv. Start manuelt fra valgt arbeidsflate. Ikke opprett oppdrag hvis samme verktøy allerede kan gjøre arbeidet direkte innen bestillingen.

Se [aktive oppdrag](aktiv/README.md) og [arkiv](arkiv/README.md).
