# Ferdigkontroll

En oppgave eller leveranse er ferdig når:

- avtalt resultat og ferdigkriterium er oppfylt
- nødvendig kilde- og innholdskontroll er utført
- riktig målflate inneholder den endelige versjonen
- lagret innhold er kontrollert ved gjenlesing eller egnet filkontroll
- oppgave og berørt saksstatus stemmer
- nødvendig godkjenning er gitt av riktig eier
- konkret restarbeid ikke skjules som ferdig.

For Git-filer: kontroller diff, struktur og integrering i riktig gren. For eksterne verktøy: kontroller riktig objekt og faktisk lagret resultat. For dokumenter: kontroller både innhold og lesbar layout.

En bestått lokal validator bekrefter bare de kontrollene programmet faktisk gjør. Sluttsvaret sier hva som er levert, hva som er uavklart og hva eieren eventuelt må gjøre.
