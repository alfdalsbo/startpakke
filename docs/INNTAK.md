# Ny informasjon

1. Registrer kilde, dato, dokumenttype og hva som faktisk er lest.
2. Finn relevant eksisterende sak eller område.
3. Skill fakta, opplysning, vurdering, beslutning, handling og idé.
4. Bevar det som har konkret fremtidig verdi hos riktig eier, med kildepeker.
5. Vurder konsekvenser for oppgave, frist, kapasitet og beslutning. Oppdater bare berørte flater.
6. Les tilbake endringer og rapporter konkret utført og uferdig arbeid.

Eksempel: Et møtereferat kan gi både ny saksforståelse og to oppgaver. Selve referatet blir liggende i originalarkivet. Saken forklarer betydningen. Oppgavene ligger i valgt kø. En kopi av samme referat på tre steder gir ikke tre kontrollerte kilder.

Ved motstrid: dokumenter hva som spriker og hvilken kilde eller myndighet som kan avklare det. Bevar sikkert historisk faktum selv om nåstatus endres.
