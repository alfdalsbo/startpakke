# Oppgaver i egen GitHub-kopi

Issue-malen i det offentlige repoet er for forbedringer av startpakken. Personlige arbeidsoppgaver opprettes i ditt eget repo etter at det er valgt som eier. Bruk [oppgavemalen](../maler/oppgave.md).

Flytt åpne oppgaver én for én med stabil kobling til nytt Issue. Marker tekstkøen `Køstatus: historisk`, sett `task_owner` til `github_issues` og angi ditt repo. Verifiser begge sider. Kontrollprogrammet leser ikke GitHub Issues; det kontrollerer at lokal eierkonfigurasjon og køstatus stemmer. Faktiske Issues må leses og prøves separat.
