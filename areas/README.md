# Varige ansvarsområder

Ingen reelle områder registrert. Opprett et område når flere saker trenger felles mål, mandat eller arbeidsmåte. Bruk [områdemalen](../maler/omrade.md) og legg lenke til filen her.

Ved vekst legges utdyping og historikk i [historikkindeksen](historikk/INDEX.md), med peker fra det berørte området. Følg [ruter og metadata](../docs/SAKSSYSTEM.md).
