# Oppgaver, ukevalg og review

Denne mappen binder saksforståelsen til konkret handling. De faste filene har ulike oppgaver:

| Sted | Eier |
| --- | --- |
| [OPPGAVER.md](OPPGAVER.md) | Handling, ansvar, frist og ferdigkriterium når `task_owner` er `markdown` |
| [UKA.md](UKA.md) | Valgt arbeid innen ukens kapasitet, med pekere til eieroppgavene |
| [reviewer](reviewer/README.md) | Daterte, historiske oppsummeringer av resultat og læring |

Bruk [oppgavemalen](../maler/oppgave.md) og velg én oppgavekø i `config/system.json`. Dersom GitHub Issues overtar, blir tekstkøen historisk med koblinger til Issues; se [overgangsregelen](../docs/GITHUB-OPPGAVER.md). Ukeplanen og reviewet blir ikke konkurrerende oppgavekøer.

Midlertidige utkast kan ligge her i egen kopi, med sakens ID, kilde og dato. Avklart kunnskap hører hjemme i [saken](../saker/README.md). Ferdige dokumenter lagres på valgt leveransested, og lenke og faktisk leveringsstatus føres i saken. Rydd utkast i ukereviewet. Ingen levende arbeidsdata følger den offentlige malen.
