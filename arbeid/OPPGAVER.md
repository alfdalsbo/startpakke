# Oppgavekø

Køstatus: aktiv

Dette er aktiv oppgaveeier når config/system.json angir markdown. Ingen reelle oppgaver registrert. Nye oppgaver følger [malen](../maler/oppgave.md), med unik ID i overskriften, for eksempel O001.

Ved overgang til GitHub Issues skal hver åpen oppgave kobles til sitt nye Issue før denne filen settes til `Køstatus: historisk`. Bevar migreringskoblingene. Endre deretter task_owner i konfigurasjonen.
